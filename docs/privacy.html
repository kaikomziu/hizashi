PRIVACY

プライバシー

Hizashi と、この公式サイトが、どんな情報をどう扱うかを説明します。

要点

  • Hizashi は、利用状況・閲覧履歴・設定・メモを、開発者や第三者に送信しません。アカウント登録も不要です。
  • ブックマーク・履歴・メモなどは、あなたのパソコンの中だけに保存されます。
  • この公式サイトには、アクセス解析・広告・Cookie の仕組みを入れていません。

Hizashi（アプリ）について

パソコンの中に保存されるもの

設定、ブックマーク、閲覧履歴、メモ、サイトごとの設定（ズーム・ダークモード・非表示にした要素・権限の許可／拒否の記憶）、前回開いていたタブ、Cookie・キャッシュなど。場所は使い方ガイドに書いています。これらは、あなたが削除するまで残ります。削除する方法も同じページにあります。

Hizashi 自身が行う通信

Hizashi は、利用状況の送信、クラッシュレポートの送信、更新の確認などを一切行いません。Hizashi が行う通信は、あなたが開いたページ（と、そのページが読み込むもの）の通信だけです。

あなたが操作したときだけ送られるもの

  • 検索：アドレスバーなどから検索すると、選んだ検索エンジン（Google・DuckDuckGo・Bing・Yahoo! JAPAN・Brave Search）に、検索語が送られます。
  • ページの翻訳：コマンドを実行すると、そのページの URL が Google 翻訳に送られます。
  • サイトへのアクセス：開いたサイトには、一般のブラウザと同じく、IP アドレスなどが伝わります。広告・計測ドメインへの通信は、設定でオンにしていれば止めます。

表示エンジン（WebView2）について

ページの表示は、Microsoft Edge WebView2 が行います。WebView2 の診断データなどの扱いは、Windows と Microsoft のプライバシー設定に従います。Hizashi では制御していません。詳しくは Microsoft のドキュメントを見てください。

Android 版について

Android 版の Hizashi も同じです。利用状況などを送信せず、ブックマーク・履歴・設定は端末の中だけに保存されます（自動バックアップも無効です）。カメラ・マイク・位置情報は、サイトが使おうとしたときに確認します。

権限

サイトがカメラ・マイク・位置情報などを使おうとしたときは、確認の画面を出します。許可した内容は、パソコンの中にだけ記憶されます。

この公式サイトについて

  • アクセス解析、広告、トラッキングは入れていません。Cookie は使っていません。
  • サイトは GitHub Pages で配信されています。そのため、GitHub がアクセスのログ（IP アドレスなど）を扱う場合があります。詳しくは GitHub のプライバシーステートメントを見てください。
  • ダウンロードのページだけは、最新版の情報（バージョン・公開日・サイズ・SHA-256）を表示するために、あなたのブラウザから GitHub の API（api.github.com）に問い合わせます。この通信は、このページを開いたときだけ行われます。
  • ダウンロードボタンを押すと、GitHub（github.com）からファイルが配信されます。
  • 画像・フォントなどは、すべてこのサイトの中のものを使っていて、外部のサービスから読み込んでいません。
