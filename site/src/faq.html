FAQ

よくある質問

聞かれそうなことを、できるだけ正直に答えています。載っていないことは、GitHub の Issuesで聞いてください。

全般

Hizashi とは何ですか？

Windows 用のブラウザです。ページを表示する部分は Microsoft Edge と同じ Chromium（WebView2）で、その上に、コマンドパレット・ワークスペース・縦タブ・分割表示・集中モード・リーダーモードなどの機能を載せた、個人開発のブラウザです。

Chrome や Edge との違いは何ですか？

ページの表示や、Web の互換性は、ほぼ同じです（同じ Chromium を使うため）。違うのは周りの機能です。キーボードで操作しやすくする工夫（パレット）、タブの整理（ワークスペース・縦タブ・分割）、集中のための機能などを中心に作っています。逆に、Chrome にある拡張機能・アカウント同期・シークレットウィンドウなどはありません。

無料ですか？ 広告は出ますか？

無料です。広告は出ません。ライセンスは MIT で、商用利用や改造も自由です。

なぜ作ったのですか？

自分が毎日使うブラウザに、ほしい機能を足していったら、公開できるものになったからです。

名前の由来は？

「日差し」です。木漏れ日（Komorebi）という名前の試作版（Electron 製）があり、そこから作り直したときに名前を変えました。

安全性・プライバシー

安全ですか？

ソースコードはすべて公開されていて、配布している exe は公開されたソースから GitHub Actions が自動でビルドしたものです。ダウンロードしたファイルは、SHA-256で照合できます。ページの表示と通信の安全性は、Chromium（WebView2）に任せています。WebView2 は、Windows Update や Microsoft のランタイムの更新で、セキュリティの修正が入ります。

ただし、個人が作った小さなソフトウェアで、第三者による監査は受けていません。重要な用途（銀行など）で使うかは、ご自身で判断してください。

情報は送信されますか？

Hizashi 自身は、利用状況・閲覧履歴・設定などを一切送信しません。詳しくはプライバシーのページを見てください。

起動すると「Windows によってPCが保護されました」と出ます

コード署名をしていないためです。「詳細情報」→「実行」で起動できます。手順はダウンロードのページにあります。

ウイルス対策ソフトが反応しました

署名がなく、数の少ないプログラムは、誤検知されることがあります。SHA-256が一致していることを確認した上で、不安な場合は使わないでください。誤検知が続くようなら、Issuesで教えてもらえると助かります。

機能

Chrome の拡張機能は使えますか？

使えません。ブラウザエンジンとして使っている WebView2 が、拡張機能に対応していないためです。広告ブロックなど、よく使われる機能は Hizashi に最初から入れています。

広告ブロックは、uBlock Origin のように強力ですか？

いいえ。Hizashi の広告ブロックは、広告・計測を行う約{{BLOCK_COUNT}}件のドメインへの通信を止めるだけの、単純な仕組みです。サイト自身が配信する広告（YouTube の動画広告など）は止められません。強力なブロックがほしい人には向いていません。

Google アカウントでログインできますか？

うまくいかない場合があります。Google は、組み込みのブラウザからのログインを「安全でないブラウザ」として拒否することがあります。Hizashi はブラウザの名乗りを Chrome に揃えていますが、確実に通ることは確認できていません。ログインできないときは、そのサイトだけほかのブラウザを使ってください。Google 以外のサイトのログインは、ふつうに使えます。

パスワードの保存や自動入力はできますか？

Hizashi 独自のパスワード管理機能はありません。入力補助は WebView2 の標準の仕組みに任せていて、動作は十分に確認していません。大切なパスワードは、専用のパスワード管理ツールを使うことをおすすめします。

シークレットウィンドウはありますか？

ありません。履歴は、履歴パネルから削除でき、Cookie とキャッシュは、パレットの「閲覧データを削除」で消せます。

ブックマークや履歴を Chrome から取り込めますか？

今のところ、インポート機能はありません。

ブックマークや設定を、別のパソコンと同期できますか？

同期はできません。手動で引き継ぐ方法は、使い方ガイドに書いています。

動画配信サービス（Netflix など）は見られますか？

YouTube や一般的な動画サイトは見られます。DRM（著作権保護）つきの配信サービスは、動作を確認していません。

日本語以外の言語に対応していますか？

画面の言葉は日本語のみです。ページを翻訳するコマンドは、Google 翻訳を使って日本語に訳します（実行すると、ページの URL が Google に送られます）。

性能・動作環境

軽いですか？ メモリはどのくらい使いますか？

「軽い」とは言えません。ページを表示する部分は Chromium なので、タブの数に応じて、Chrome や Edge と同じくらいのメモリを使います。Electron 製の試作版と同じ条件で測ったところ、ほぼ同じ水準でした。使っていないタブを休止する機能で、使用量を抑えられます。

exe が約46MBもあるのはなぜですか？

.NET の実行環境を exe の中に詰め込んでいるためです（そのおかげで、別途インストールが要りません）。.NET 9 のランタイムを入れている人は、ソースから約1.9MBの小さい版もビルドできます。

Windows 7 / 8 や Mac、Linux、iPhone、Android では使えますか？

Windows 版は、Windows 10 / 11 の64ビット版だけです。Mac・Linux・iPhone 版はありません。Android 向けには、別のアプリとして試験版を公開しています（Android 10 以降）。ダウンロードのページを見てください。

起動しません

使い方ガイドの「困ったとき」を見てください。

更新・削除

更新はどうすればいいですか？

自動更新はありません。ダウンロードのページから新しい exe を入手して、古い exe と入れ替えてください。データはそのまま引き継がれます。

どうやって削除しますか？

exe を削除するだけです。データも消したい場合は、データの保存場所のフォルダを削除してください。

開発・ライセンス

ソースコードは見られますか？ 改造や再配布はできますか？

GitHubで公開しています。MIT ライセンスなので、改造・再配布・商用利用が自由にできます（著作権表示とライセンス文は残してください）。

要望や不具合はどこに伝えればいいですか？

GitHub の Issuesへどうぞ。個人開発なので、対応には時間がかかることがあります。セキュリティ上の問題は、公開の場ではなく、セキュリティポリシーの方法で連絡してください。

開発に参加できますか？

歓迎です。CONTRIBUTING.mdを見てください。
