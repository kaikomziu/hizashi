更新履歴

最新版は v1.0.1 です。新しい版はダウンロードのページから入手できます。

v1.0.1 2026-10-28

  • 新しいタブを開いた直後などに、ショートカットキー（Ctrl+W など）が効かないことがある問題を軽減しました。 フォーカスが WebView2 の外側のコントロールにあるときも、ウィンドウ側でキーを受け取って処理します。
  • 自動テストを強化（101項目）。実キー入力の検証は、キーがアプリに届いたかどうかを区別するようにしました。

v1.0.0 2026-10-28

最初の公開版。

  • コマンドパレット（Ctrl+K）、ワークスペース、縦タブ、分割表示、集中モード
  • リーダーモード、要素ブロッカー、強制ダークモード、サイトごとのズーム記憶
  • 広告・トラッカーのブロック（ドメイン単位）、HTTPS 自動アップグレード、追跡パラメータの除去
  • タブの自動休止、前回のタブの復元、閉じたタブの復元
  • スクリーンショット（表示範囲 / ページ全体）、クイックメモ、ダウンロード管理、ページ内検索、PiP
  • アドレスバーの検索ショートカット（yt ねこ など）、新しいタブページ（時計・TODO）
  • exe 1つで動作（UI は exe に埋め込み）。デスクトップ/スタートメニューへのショートカット作成コマンド

この履歴は、リポジトリの CHANGELOG.md から自動で作っています。各リリースの詳細は GitHub のリリースにもあります。
