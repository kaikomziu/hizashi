はじめかた

  1. ダウンロード
    ダウンロードした Hizashi.exe を、好きなフォルダに置きます（デスクトップなど）。
  2. ダブルクリック
    起動します。初回は画面が出るまで少し待つことがあります。
  3. 必要なら SmartScreen を通す
    次の「SmartScreen の警告が出たら」を見てください。

SmartScreen の警告が出たら

Hizashi は、コード署名（有料の証明書）をまだ付けていません。そのため、初回の起動で次のような画面が出ることがあります。

「Windows によってPCが保護されました」と表示され、「実行」ボタンが見えない。

  1. メッセージの中の「詳細情報」をクリックします。
  2. 下に出てくる「実行」ボタンをクリックします。

これは「まだ多くの人に使われていないプログラム」に出る警告で、危険だと判定されたという意味ではありません。それでも不安なときは、次の方法で確かめられます。

  • ソースコードはGitHubで全部公開されています。
  • 配布している exe は、GitHub Actions が公開されたソースから自動でビルドしたものです（ビルドの記録）。
  • 下の方法で、ダウンロードしたファイルが正しいものか照合できます。

それでも使いたくない場合は、無理に使う必要はありません。

ファイルが正しいか確かめる（SHA-256）

ダウンロードしたファイルが、公開されたものと同じかどうかを、SHA-256 というハッシュ値で確かめられます。

  1. exe を置いたフォルダで、Shift を押しながら右クリック →「PowerShell ウィンドウをここで開く」（または「ターミナルで開く」）。
  2. 次のコマンドを実行します。 
    Get-FileHash .\Hizashi.exe -Algorithm SHA256
  3. 表示された Hash の値が、次の値と一致していれば同じファイルです。
（最新版の値は、リリースのページにある SHA256SUMS.txt と、リリースノートに載っています）

このページの値は、GitHub のリリースノートを読み込んで表示しています。表示されないときは、リリースのページを直接見てください。

Windows 版を Android 向けに作り直した別のアプリです。表示には端末の「Android System WebView」（Chromium）を使います。コマンドパレット、広告・トラッカーのブロック、集中モード、リーダーモード、要素ブロッカー、強制ダークモードなどがあります。ワークスペース・縦タブ・分割表示・クイックメモ・スクリーンショットは、Android 版にはありません。

まだ試験版です。実機での動作確認が十分ではありません。うまく動かないところは、GitHub の Issuesで教えてください。

インストールのしかた

  1. 上のボタンから APK をダウンロードして、開きます。
  2. 「このアプリのインストールを許可しますか？」と出たら、いま使っているブラウザ（またはファイル管理アプリ）に対して「この提供元のアプリを許可」をオンにします。
  3. 「インストール」を押して、起動します。

Google Play には出していません。そのため、Play プロテクトが「不明なアプリ」と警告することがあります。APK は、公開されたソースから GitHub Actions が自動でビルドして、個人の鍵で署名したものです。ダウンロードしたファイルが正しいかどうかは、リリースのページにある SHA256SUMS.txt の値と照らして確かめられます。同じ鍵で署名しているので、新しい版は上書きインストールで、データを残したまま更新できます（自動更新はありません）。

できないこと：拡張機能、シークレットタブ、アカウント同期。広告ブロックはドメイン単位です。Google アカウントでのログインは、うまくいかない場合があります（未検証）。詳しくはAndroid 版の READMEを見てください。

更新するには

自動更新はありません。新しい版が出たら、このダウンロードのページから新しい exe を入手して、古い exe に上書き（入れ替え）してください。設定・ブックマーク・履歴などは別の場所に保存されているので、そのまま引き継がれます。新しい版の内容は更新履歴にあります。

削除するには

インストールをしていないので、Hizashi.exe を削除するだけで終わりです。データも消したいときは、使い方ガイドのデータの場所にあるフォルダを削除してください。ショートカットを作っていた場合は、デスクトップとスタートメニューのショートカットも削除します。

小さい版（上級者向け）

配布している exe は、必要なものをすべて詰めた「自己完結版」で、約 46 MB あります。.NET 9 デスクトップ ランタイムを入れているパソコンなら、ソースから約 1.9 MB の小さい版を自分でビルドすることもできます。手順はリポジトリの README にあります。

ソースからビルドする

.NET 9 SDK が入っていれば、自分でビルドできます。

git clone https://github.com/kaikomziu/hizashi.git
cd hizashi
dotnet build -c Release

詳しくはCONTRIBUTING.mdを見てください。
